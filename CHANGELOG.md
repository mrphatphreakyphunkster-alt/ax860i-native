# Changelog

## 0.1.0 — 2026-10-22 — experimental prerelease

* Source-only curated native USB/hwmon driver, five-page DC power total and
  hidden raw AC-current slot; optional curve-estimate readout companion.
* Explicit-target DKMS build and no-overwrite, manifest-verified persistence
  installer; narrow binder with original-owner recovery and busy-TTY refusal.
* Self-contained offline tests; public install, recovery and limitation docs.
* Public provenance replaces private paths; independent copied scripts/tests/
  rules/config carry GPL-2.0-only SPDX notices. No behavior change to
  the installer/driver, no invented author, and no claim of legal clearance.
* Maintainer-authorized whole-release GPL-2.0-only licensing; public repository
  and GitHub Issues contact under mrphatphreakyphunkster-alt.
* Source publication performs no root installation, active-driver change or
  additional hardware test; this is not a production-ready or upstream release.
